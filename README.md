# praxis-seo-reports
Oeffentliche SEO/Praxis-Reports fuer naturheilpraxis-straehuber.de (nur Berichte, kein Code)

Dieses Repo enthaelt ausschliesslich Analyse-Reports und Entwuerfe aus `/root/praxis-seo/output/` auf dem Praxis-Server – bewusst oeffentlich, damit sie per Link (z.B. ueber raw.githubusercontent.com) direkt gelesen werden koennen, ohne manuelles Teilen.

**Kein Code, keine Zugangsdaten.** Die eigentlichen Skripte (wp_publish.py, ahrefs_tool.py) liegen weiterhin privat im Repo `praxis-seo-tools`.

Alle Berichte liegen unter [`reports/`](reports/).
